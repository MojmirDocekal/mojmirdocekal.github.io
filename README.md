# mojmirdocekal.github.io

Personal academic hub for **doc. PhDr. Mojmír Dočekal, Ph.D.** (Associate Professor at the Department of Linguistics and Baltic Languages, Masaryk University, Brno).

Hosted via [GitHub Pages](https://mojmirdocekal.github.io).

## Features

- **Zero-dependency & lightning fast**: Pure semantic HTML5 + modern CSS (no build steps, gems, or npm packages).
- **Core Academic Hub**:
  - [Publications](https://scholar.google.com/citations?user=9fcboJ4AAAAJ&hl=cs) (Google Scholar)
  - [Projects](https://www.muni.cz/lide/15952-mojmir-docekal/projekty) (Masaryk University)
  - [Teaching](https://www.muni.cz/lide/15952-mojmir-docekal/vyuka) (Masaryk University)
  - [ORCID Record](https://orcid.org/0000-0002-9993-4756)
- **Automatic Dark/Light Mode**: Matches system preference with a manual override toggle stored in `localStorage`.
- **Side Quests & Toy Projects Section**: A discreet collapsible drawer (accessible on the page or via `#toys`) featuring [sandbox2026](https://github.com/mojmirDocekal/sandbox2026) (slides & notes) and the [Pig Dice Game](https://mojmirdocekal.github.io/pig-dice-game/).
- **Publications Archive**: Clean raw [`publications.bib`](publications.bib) preserved in the repository.

## Legacy Archive

The legacy Jekyll files and posts from 2014–2020 are preserved in the `archive/` directory.
